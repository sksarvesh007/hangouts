lets get started with this

backend is in python - fastapi 
frontend is in nextjs

backend directory: ./backend
frontend directory: ./frontend

to run backend, make sure you have uv installed, then run:
```bash
cd backend
uv run main.py
```
run this if you haven't set up the environment yet:
```bash
uv sync
```

to start the backend run:
```bash
uv run main.py
```

Frontend : 
it uses pnpm as package manager, and runs on port 3000

To start the frontend, run:
```bash
cd frontend
pnpm install
pnpm run dev
```

The frontend will be available at http://localhost:3000
